# Local environment definitions

# 本地环境定义

公开版有意不包含具体站点的环境清单与服务文件。请依据获批的环境信息在本地创建 `inventory.yaml` 和 `services.yaml`，使用前完成配置校验。不得向公开仓库提交内部地址、凭据、私钥或生产主机身份信息。

This directory intentionally excludes site-specific inventory and service files
from the public edition. Create `inventory.yaml` and `services.yaml` locally from
your approved environment information, then validate them before use. Never add
internal endpoints, credentials, private keys, or production host identities to
the public repository.
